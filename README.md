🛡️ Tríada CIA - Infografía Interactiva & Laboratorio de Ciberseguridad

Vista: https://app-react-sage-sigma.vercel.app/

Una aplicación web interactiva desarrollada con React, Vite y Tailwind CSS diseñada para enseñar y poner a prueba de forma visual y práctica los tres pilares fundamentales de la ciberseguridad: Confidencialidad, Integridad y Disponibilidad (Tríada CIA).

🚀 Características Principales

📐 Diagrama Interactivo CIA: Modelo triangular con nodos de navegación fluida para explorar las definiciones, conceptos clave y defensas de cada pilar.

🧪 Laboratorio de Simulación Práctica:

Confidencialidad: Demostrador interactivo de cifrado/descifrado con clave secreta.

Integridad: Generador de firmas Hash SHA-256 para observar el Efecto Avalancha ante cualquier pequeña alteración en los datos.

Disponibilidad: Simulador de resiliencia y failover (conmutación por error) en clústeres de servidores.

⚡ Simulador de Ciberamenazas: Análisis de impacto paso a paso para ataques reales como DDoS, Ransomware, Man-In-The-Middle, Phishing de credenciales e Inyección SQL (SQLi).

🧠 Quiz de Conocimientos: Módulo de evaluación con 5 casos prácticos, retroalimentación explicativa inmediata y contador de puntuación.

📋 Checklist de Auditoría: Lista de verificación técnica para medir el nivel de madurez de seguridad con una barra de progreso en tiempo real.

🎨 Diseño Moderno & Responsivo: Interfaz en tonos Verde Esmeralda, Menta y Blanco, altamente legible y optimizada para cualquier pantalla.

📦 Instalación y Configuración Local

Sigue estos pasos para clonar y ejecutar el proyecto en tu máquina local:

1. Clonar el repositorio

git clone https://github.com/TU_USUARIO/app-react.git
cd app-react


2. Instalar las dependencias

npm install


3. Iniciar el servidor de desarrollo

npm run dev


Abre tu navegador e ingresa a http://localhost:5173.
